# Template attribution

The four `setup-*.tex` files are copied unchanged from the user-supplied
`reports/Template/beamer-presentation/` template.

Its README identifies the upstream as
[Karl-Ludwig Besser's beamer-presentation-template](https://github.com/klb2/beamer-presentation-template),
licensed under [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0).
The presentation uses [Metropolis](https://github.com/matze/mtheme),
by Matthias Vogelgesang and contributors, distributed separately through TeX Live
under CC-BY-SA 4.0. This folder does not redistribute the theme implementation.

The Chinese content, experiment tables, plots and slide-specific settings were
added for this report. Fira Sans is selected when installed; otherwise the
portable build uses TeX Gyre Heros. The supplied theme colors are retained.
