% The pinned image resolves Fira Sans/Mono by FILE via kpathsea (TeX Live
% ships them), but NOT by fontconfig FAMILY name — `fc-list` has no "Fira

% for the family name, silently fails the probe, and falls back to the
% default LaTeX font with only a PackageWarning. Loading the exact OTF
% filenames explicitly (by stem, resolved via kpathsea) keeps the theme's
% actual Fira look instead of a silent substitution.
